# 내 차 연료 건강검진 — 공개 체험판

- GitHub Pages: main / (root), Deploy from a branch.
- `index.html`, `assets/data.json`, `.nojekyll`을 저장소 루트에 배치합니다.
- 기존에 직접 다운로드한 세종글꽃체 파일을 `assets/sejong.ttf`로 복사합니다. 글꼴 저작권: 세종특별자치시. 배포 전 공식 글꼴 이용 조건을 확인하세요.
- 실제 학습 모델을 사용하려면 별도 제공한 `export_pages_models.py`를 기존 FuelSignal 폴더에서 실행한 후 생성한 `models.json`을 `assets/models.json`으로 복사합니다. 변환 검사에 통과한 경우만 사용하세요. 파일이 없으면 실제 연비 계산만 제공하며 AI 경보는 제공하지 않습니다.
- OCR은 공개 체험판에서 지원하지 않습니다. 주유 기록 직접 입력과 영수증 이미지 미리보기만 제공합니다.
- 차량 기록은 브라우저 localStorage에 저장되며 기존 SQLite와 공유되지 않습니다. 회원 인증, 기관 전송, 동기화는 지원하지 않습니다.
- 자료 출처는 홈페이지에 표시됩니다. 국내 공공데이터는 제공 당시 스냅샷이며 최신 정보 및 연료 품질을 보장하지 않습니다. 게시 전 각 원본 데이터의 공개·재이용 조건과 공모전 공개 제한을 확인하세요.
- 실제 불량연료 판정 시스템이 아닙니다. 연구 결과는 가상 주유 구간 및 합성 소비 증가 실험을 포함합니다.
